# 手机自动化助手

基于 **Auto.js 系列（推荐 AutoJs6）** 的手机自动化工具：**识别关键元素 → 自动点击 → 自动上下滑动**。开源免费、免 Root，靠安卓系统的「无障碍服务」工作。**支持打包成独立 APK 安装使用**。

## 它能做什么
- 识别关键元素：按 **文字** / **content-desc** / **资源ID** 三种方式定位
- 自动点击目标元素
- 自动 **向上滑** / **向下滑**（翻页）
- 自动下滑 **直到找到** 某个目标文字，然后停住点击
- 查看当前前台 App 包名 / Activity / 屏幕尺寸
- 导出当前界面控件树（用于定位元素）

## 目录结构
```

├── README.md        # 本说明
├── CHANGELOG.md     # 更新日志

```

## 两种使用方式

### 方式一：在手机上直接运行脚本
1. 手机安装 **AutoJs6**（官方下载：http://download.autojs6.com 或 GitHub Releases）。
2. 打开 AutoJs6 → 授权 **无障碍服务** + **悬浮窗**。
3. 导入本项目文件夹，点 ▶ 运行 `main.js`。

### 方式二：打包成独立 App（就是"软件"）
在 AutoJs6 里：**导入本项目 → 点「打包」→ 生成 APK**。把这个 APK 装到手机上，就是一个独立 App，打开点一下就能用，不需要每次都进 AutoJs6。

> 打包成 APK 需要在你手机上的 AutoJs6 里做（或装 Android Studio/构建环境）。它的本质是把你这段脚本 + Auto.js 运行时打包成一个安卓 App。

## 常见使用示例
| 你想做的 | 操作 |
|---|---|
| 点屏幕上的「发布」 | 菜单 1 → 输入「发布」 |
| 一直往下翻 | 菜单 4（可输入次数） |
| 下滑找「关注」并停 | 菜单 6 → 输入「关注」 |

| 找不到元素时定位 | 菜单 7 查看控件树 |

## 说明
- 仅支持 **Android**（免 Root）；iOS 无此"开箱即用"方案。
- 依赖无障碍服务识别控件，元素以文字 / ID 为准；App 界面常变时优先用 desc / 资源ID。
- 部分 App 反自动化检测，可能点不动或闪退，属正常现象。
