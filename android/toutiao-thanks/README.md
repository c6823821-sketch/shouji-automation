# 头条点赞感谢 Android 版

这是一个不需要电脑、ADB、scrcpy 或 root 的安卓无障碍辅助程序。

## 功能

- 顺序点击今日头条点赞通知中的“谢谢”
- 点击同一行的“私信「谢谢点赞」”
- 如果出现单独的“发送”按钮，会自动发送
- 当前页完成后，只执行竖直向上滑动
- 连续多次没有新内容后自动结束
- 返回键最多按两次，不会连续返回主页

## 使用

1. 安装 APK。
2. 开启本软件的无障碍权限。
3. 打开今日头条，进入“我的 → 消息/互动 → 点赞”。
4. 回到本软件，点击“开始自动感谢”。

## 更新

软件会通过本仓库的 GitHub Releases 检查更新。发现新版本后，在软件内下载并进入安卓安装确认界面。

## 构建

Windows 下需要 JDK 和 Android SDK，然后运行：

.\build_apk.ps1
